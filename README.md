## 5. 校验器与假阳性登记

发布前扫描器在四处出现**同族假阳性**——规则匹配「形态相似」而非「结构判别」。四类均已改结构判别处置：

| 告警 | 实为 | 结构性修复 |
|---|---|---|
| 11 位数字疑似手机号 ×36 | π 的小数展开、SHA256 十六进制串 | 词边界 + 十六进制/小数上下文排除 |
| 「预算/基金/经费」×56 | 数学术语 `误差预算`、技术术语 `剂量预算` | 术语上下文排除 |
| 盘符路径 | Python 字符串的转义换行 | 要求后随路径段，排除转义序列 |
| 尖括号「占位符」×4 | 散文比较符（th 小于 pi/2）、HTML 换行标记 | 改为结构判别 + 仅作用于 Markdown/JSON |

- 判据档案与自测规模见 [VERIFY_NOTES.md](VERIFY_NOTES.md)
- 自审计逐条裁决见 [SELF_AUDIT.md](SELF_AUDIT.md)
- 与 U+FFFD 同源的一类教训：**缺陷标记符与被记录证据同形，会使扫描在该文件上恒假阳性、信号归零**。处置不是改措辞，而是把判据档案集中到声明式记录文件，使「记录」与「实例」职责分离
