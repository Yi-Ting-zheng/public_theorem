## 1. 前提：Schanuel 猜想 (S)

> **猜想 (S)**：若 `z₁,…,z_n ∈ ℂ` 在 ℚ 上线性无关，
> 则 `ℚ(z₁,…,z_n, e^{z₁},…,e^{z_n})` 的超越度 `trdeg ≥ n`。

**注意**：S 的常见错误形式是「n 个数中至少 n 个代数无关」——
那**不是**标准陈述。标准形式是**超越度** ≥ n
（允许生成元多于 n 时更精细的代数无关性结论，本文件只用 trdeg 形式）。

**状态**：`GAP-OPEN`。**不可默认使用。**

**rev11 实例说明**：本文件仅需 S 的下列**两个实例**（TC-4′）：
`(S)₂ @ (ln π, 2πi)` 与 `(S)₄ @ (1, 2πi, ln π, π·ln π)`。
其中 `(S)₂ @ (ln π, 2πi)` 取代旧链的 `(S)₂ @ (1, 2πi)` 与 `(S)₃ @ (1, 2πi, ln π)`。

## 2. 推导链（3 步，2 次应用 (S)）

> **rev11 重构**：旧链（rev10 及以前，4 步 3 次应用，含 `(S)₃`）的 `(S)₃`
> 应用是**冗余**的（见 §2.4 与 §5.1 记录）。现行链如下。

### 步骤 1 —— `(S) @ n=2`（`z = (ln π, 2πi)`）：π 与 ln π 代数无关

> **⚠ 本步的 `ln π ∉ ℚ` 在无条件下是公开开放问题（`GAP-3`），不得无条件引用。**
> 四源确认见 `04_缺口/缺口登记.md` `GAP-3` 与 `01_文献/文献基线.md` §1.4。
> 本步能写成 `ln π ∉ ℚ` 的**唯一依赖**是 `(S)₂` 实例本身。

**取** `z₁ = ln π`, `z₂ = 2πi`。

**ℚ-线性无关**：
设 `a·ln π + b·2πi = 0`，`a, b ∈ ℚ`。
取虚部：`b·2π = 0` ⟹ `b = 0`（`π ≠ 0`）。
再 `a·ln π = 0` ⟹ `a = 0`（`ln π ≈ 1.1447 ≠ 0`）。 ✓

**`e^z`**：`e^{ln π} = π`，`e^{2πi} = 1`。

**应用 (S)**：
$$\mathrm{trdeg}\,\mathbb{Q}\big(\ln\pi,\;2\pi i,\;\pi,\;1\big) \;\ge\; 2$$

生成元化简：`2πi = 2i·π` 且 `i = (2πi)/(2π) ∈` 该域（`π ≠ 0`，
`2π ∈ ℚ(π) ⊂` 域），故域为 `ℚ(ln π, π, i)`；
`i` 为代数数不影响超越度 ⟹ `trdeg ℚ(ln π, π) ≥ 2`。
两个生成元、trdeg ≥ 2 ⟹ **`π` 与 `ln π` 在 ℚ 上代数无关**。 ∎

**关键副产物**：`ln π ∉ ℚ`——若 `ln π = r ∈ ℚ`，`Y − r ∈ ℚ[X,Y]`
非零多项式在 `(π, ln π)` 消零，与代数无关矛盾。

> **外部佐证（L-AP4，rev11）**：ProofWiki «Schanuel's Conjecture Implies
> Algebraic Independence of Pi and Log of Pi over the Rationals» 用**同一实例**
> `z = (ln π, iπ)`（本项目取 `2πi`，同构）独立推得同结论——本项目推导与
> 外部标准谱系一致。见 `01_文献/文献基线.md` §1.9。
>
> **隐依赖校验（rev11 增补）**：本步应用 `(S)₂` 的前提是 `ln π, 2πi ∈ ℂ`
> （平凡成立）且二者 ℚ-线性无关（已证）。**注意：Schanuel 猜想本身是全域
> 猜想；本项目仅调用猜想的特定实例，并非假设猜想整体成立。**
>
> **逻辑区分（关键）**：全域 `(S)` **蕴涵** `(S)₂` 实例，反向不真——
> `(S)₂ @ (ln π, 2πi)` 是一个**更弱的独立条件**。`TC-4′` 只依赖
> **两个特定实例**（本步 `(S)₂` + 步骤 3 的 `(S)₄`）的**合取**，
> **弱于**完整 Schanuel 猜想。**不得**把「假设 Schanuel 猜想」与
> 「假设 TC-4′」视为等价——二者粒度不同。

### 步骤 2 —— `1, 2πi, ln π, π·ln π` 在 ℚ 上线性无关

> **这是全链条唯一的非平凡引理**，也是最容易出错的一步（承旧链易错点登记）。

设 `a + b·2πi + c·ln π + d·(π·ln π) = 0`，`a,b,c,d ∈ ℚ`。
取虚部：`b·2π = 0` ⟹ `b = 0`。再取实部：

$$a + c\ln\pi + d\,\pi\ln\pi = 0 \quad\Longleftrightarrow\quad a + (c + d\pi)\ln\pi = 0 \qquad (\star)$$

**情形 d = 0**：
`(\star)` 退化为 `a + c·ln π = 0`。由**步骤 1 副产物** `ln π` 无理 ⟹ `c = 0` ⟹ `a = 0`。 ✓

**情形 d ≠ 0**：
`(\star)` 是 `π` 与 `ln π` 间的多项式关系

$$d\,X\,Y + c\,Y + a = 0, \qquad (X,Y) = (\pi,\ \ln\pi)$$

因 `d ≠ 0`，该双变量多项式**非零**。
这与**步骤 1** 结论「`π` 与 `ln π` **代数无关**」矛盾。 ⟹ `d ≠ 0` 不可能。 ✓

**两情形皆得**：`a = b = c = d = 0`，四个数 ℚ-线性无关。 ∎

> **易错点登记（对应 `01_文献/文献基线.md` A7 纪律）**：
> 本步若只用「`ln π` 无理」而**不**用「`π, ln π` 代数无关」，
> 则 `d ≠ 0` 情形无法排除，**整条 (S)@n=4 应用失效**。
> 「π ln π」中 `π` 与 `ln π` 的**乘积**形式正是需要**对**（而非单数）的超越性的原因。
> **rev11 备注**：这一「对」由 `(S)₂` 提供（旧链曾由更强但冗余的 `(S)₃` 三元组提供）。

### 步骤 3 —— `(S) @ n=4`（`z = (1, 2πi, ln π, π·ln π)`）：π^π 超越 ∎

**取** `z₁ = 1`, `z₂ = 2πi`, `z₃ = ln π`, `z₄ = π·ln π`。

**ℚ-线性无关**：由**步骤 2**。 ✓

**`e^z`**：
- `e^1 = e`
- `e^{2πi} = 1`
- `e^{ln π} = π`
- `e^{π ln π} = π^π`  ← **目标项**

**应用 (S)**：
$$\mathrm{trdeg}\,\mathbb{Q}\big(1,\;2\pi i,\;\ln\pi,\;\pi\ln\pi,\;e,\;1,\;\pi,\;\mathbf{\pi^\pi}\big) \;\ge\; 4$$

生成元化简：`{π, ln π, e, π^π}`（4 个）。
trdeg ≥ 4 且恰 4 个生成元 ⟹ **四者代数无关**。

⟹ `π^π` 为超越数。 **∎** ∎ ∎

## 4. 姊妹定理与可迭代性

### 4.1 TC-3（π^e）

**同样的配方**，把步骤 2、3 中的 `π·ln π` 换成 `e·ln π`：

- 步骤 2′：`1, 2πi, ln π, e·ln π` ℚ-线性无关
  （`d ≠ 0` 情形给出 `e` 与 `ln π` 间的非零多项式关系，
  由「`e, ln π` 代数无关」排除）
- 步骤 3′：`e^{e ln π} = π^e`

⟹ `π, ln π, e, π^e` 代数无关 ⟹ `π^e` 超越。 ∎

### 4.2 一般配方

对任意 `u`，若能证明 `1, 2πi, ln π, u·ln π` ℚ-线性无关，则 `(S)@n=4` 给出

$$\pi,\ \ln\pi,\ e,\ \pi^u \quad \text{代数无关}$$

**该配方的适用条件**（`d ≠ 0` 情形）：
`u` 与 `ln π` 之间不得有多项式关系。
`u = π`：`π, ln π` 代数无关 ✓（由 `(S)₂ @ (ln π, 2πi)` 给出，rev11）
`u = e`：`e, ln π` 代数无关 ✓（但**该对需要 (S)₃**，见 §4.3）
`u = e^π`：**需额外 (S) 应用**（Marques–Sondow 的 17 元素集即多轮迭代所得）

**这是本链条的结构性产出**：一个可复用的降维配方。

> **配方约束补充（rev11 增补）**：对一般 `u`，即便 `u` 与 `ln π` 代数无关，
> 仍**必须额外核验**四元组 `1, 2πi, ln π, u·ln π` 的 ℚ-线性无关性——
> 代数无关性**仅**用于排除 `d ≠ 0` 分支，**不足以自动保证线性无关**
> （还需 `u` 自身的无理性/超越性来排 `a, c` 分支）。本例 `u = π` 是
> **同时满足两条的特例**，不是通用自动成立的结论。

### 4.3 rev11 实例数不对称（对配方的重要性）

`π^u` 的 `d ≠ 0` 排除需要 **「`u`, `ln π` 代数无关」**。不同 `u` 其供给实例不同：

| `u` | 所需对 | 供给实例（(S)） | 备注 |
|-----|--------|----------------|------|
| `π` | `{π, ln π}` | `(S)₂ @ (ln π, 2πi)` | **2 个实例即可**（TC-4′） |
| `e` | `{e, ln π}` | `(S)₃ @ (1, 2πi, ln π)` | 该对**不能**由单 (S)₂ 实例给出：取 `z=(1, ln π)` ⟹ 域 `ℚ(ln π, e, π)` 三生成元而 `trdeg ≥ 2`，只给「三中某两」无关，定位不到 `{e, ln π}` |

⟹ **TC-4′（`(S)₂∧(S)₄`）专属于 `u = π`（本项目 `GAP-1`）的链条**，
**不得**视为 TC-3（`π^e`）或一般配方的通用弱化。此为 rev11 正确性边界之一。
