## 0. 课题定位（唯一权威表述）

> **本课题不承诺证明 π^π 无理。**
> 课题目标是把「π^π 有理 ⟹ 矛盾」这条归约链**走到最远、写到最干净**，
> 并把链条最终卡住的位置**精确定位为一个最小的、显式写出的未证命题**。

理由见 `00_立项/立项勘误与定位修正.md` §2。简述：

- 一阶（有理性）是百年未决难题，直接证伪的期望值极低。
- 但「归约链的形式化与缺口最小化」是可完成、可复现、可发表的**逻辑工作**，
  且不依赖任何新的数学突破。
- 失败条件因此从「我证不出来」变成「我整理得不干净」——后者可控。

**本项目唯一的成功判据**：链条每一步都标注真值层级，
每一步都能被一次具体检索证伪，缺口被压缩到一个显式命题。

## 3. 真值分层纪律（硬约束）

本项目继承 V5 项目的纪律，**违反等同于系统故障**：

1. **每条断言必须标真值层级**，无标签的断言不得进入定稿文档。
2. **`THEOREM` 需要完整证明链**，不接受「数值收敛」或「多模型支持」。
3. **条件性结论一律标 `THEOREM-COND`**，前提须显式写出（如 Schanuel 猜想）。
4. **`FALSIFIED` 保留归档**，不作废删除。证伪是记录，不是历史。
5. **撤回（retraction）必须留痕**：写明原断言、撤回原因、取代者——**三要素写全才算留痕**，
   不依赖 `RETRACTED` 标签（见 §4 编号约定）。
6. **禁止在定理框内混入 `EMPIRICAL` 常数**（V5 曾因此发生定理框违规，见 `archive`）。
7. **禁止算力替代证明**。计算只能排除候选路径，不能确立结论。
8. **每条断言应能被一次具体检索证伪**。做不到的，降级为猜想或删除。

10. **转换层失真纪律（`F-10a`，2026-09-28）** ——
    从 **arXiv HTML / ar5iv / PDF 文本层**抄录文献时：
    - ✅ 其**书目**（作者、卷期页码、DOI）**可直接采信**；
    - ❌ 其**结构记号**（`\overline`、上标嵌套、上下标）**不可直接采信** ——
      转换层会**静默丢失**这些记号，从而**改变数学对象**。
    - **必须**核对题名/定理措辞中的**字面重复**是否可疑（如 `U` vs `UU`）；
    - **必须**另取 **≥1 个独立源**验证题名与**作者全名**；
    - 由转述取得的定理**措辞**一律标「**转述**」，**不得**记为「原文核实」。
    - 权威细则见 `01_文献/文献基线.md` §5；失效实例见 `F-10`。

      风险高于结论所涉及的定理。**定义错 ⟹ 其上所有推断连锁作废**，
      而这些推断往往**形式完备、四源齐备、篇幅可观**，
      因而不易被读者察觉（`F-12` 即是「四分穷尽 + 互斥」这类完备性论证的产物）。
    - **不得从二手综述/教程页引入判别性定义**（含未定义量、缩写未交代、
      与主源表述不一致者）；定义须回到**≥2 个相互独立的一手/权威源**逐条比对。
    - **必须区分「同一符号的不同量」**。本项目实例：rev07/rev08 把
      `w(ξ) = limsup_n w_n(ξ)/n`（分类判据）与 `μ(ξ) = w₁(ξ)`（无理度）
      **混为一谈**。⟹ 凡「`X` 有限」类推理，**必须先写清 `X` 由哪个 `n` 支配**，
      再问该推理对**其余 `n`** 是否成立。
    - **不可访问的源（HTTP 403 / timeout）不得作为定义依据**；
      `elibm.org/ft/10012007000` 即属此类，其 Definition 3.5 已被判定**不可靠**。
    - **自审触发器**：文档内出现「**必为**」「**必不**」「完全」「彻底」「终局封闭」
      等**封闭性词汇**时，强制回查其**判据定义**本身是否为多源核实。
      `F-12` 的外部佐证：Wikipedia 对 `e` **明确**称 S-数、对 `π` **只**说
      「known not to be a U number」——**同一文档内的措辞不对称**是分类断言越界的强信号。
    - 权威细则见 `01_文献/文献基线.md` **§5c**（R9 完整证据链）；
      失效实例见 `F-12`（定义级错引导致「必为 S-数」越界）。
